# build-your-own-claude-code

Content for the "Build your own Claude Code" challenge

## Setup

This challenge is developed using https://github.com/codecrafters-io/course-sdk. Read the README there for information
on how to contribute language support & submit solutions.

## Local full-feature reference

To run a **complete** agent locally (Read, Write, Bash, Skill tool, and all Skills extension stages), see [docs/LOCAL_DEVELOPMENT.md](docs/LOCAL_DEVELOPMENT.md). Prefer `playground/rust/` on Apple Silicon; `playground/python/` is the same behavior. Project skills for Claude Code live under `.claude/skills/`.
